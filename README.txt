Dhanvix  - Expense Tracker (HTML + CSS + JavaScript)

FILES (keep them together in ONE folder, with these exact names)
  index.html      page structure
  style.css       colors, glass look, 3D effects, layout
  script.js       all the logic (pages, charts, saving data)
  background.jpg  background photo (the app still works without it)

HOW TO RUN
  1. Unzip the folder.
  2. Open the folder in VS Code (File > Open Folder).
  3. Right-click index.html > "Open with Live Server".

Needs internet only for the Outfit font; everything else works offline.
Your data is saved in the browser (localStorage). Use Setting > Clear all saved data to reset.
